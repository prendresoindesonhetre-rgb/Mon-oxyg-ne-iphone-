# Les petits gestes de mon Hêtre

Application Android hors-ligne de micro « coupe-circuits » de 10 secondes à quelques minutes.

- identité visuelle douce turquoise / bleu ciel / violet
- aucun compte, aucune publicité, aucune collecte de données
- favoris et historique uniquement en local
- animation respiration : feuille de Hêtre portée par le vent
- exercices illustrés, notamment langue relâchée, prochaine pensée, appui des pieds, double soupir, tips du quotidien

Le build GitHub Actions produit un APK de test Android.
